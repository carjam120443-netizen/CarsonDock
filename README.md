<p align="center">
  <strong>A lightweight, macOS-inspired launcher for Android.</strong><br>
  Built to feel like a desktop dock while staying native to Android.
</p>

> 🚧 **Early development** — CarsonDock is currently a foundation project. The launcher UI and features are being built incrementally.

## ✨ Planned features

- 🖥️ Desktop-style Android home screen
- 🪟 macOS-inspired dock with smooth animations
- 🚀 Launchpad-style app drawer
- 🔎 Spotlight-inspired app search
- 🖼️ Custom wallpapers
- 📱 Android app launching and launcher integration
- 🧩 Widget support
- 📁 Desktop folders
- 🎨 Customizable dock, icons, spacing, and appearance
- 🔋 Lightweight design focused on low overhead
- 📐 Support for phones, tablets, and larger Android displays

## 🛠️ Tech

CarsonDock is being built with **Kotlin**, **Jetpack Compose**, and standard Android launcher APIs.

The project currently contains the initial Android launcher application structure and a simple launcher activity. More functionality will be added as development progresses.

## 🎨 Icon

The current CarsonDock icon is an original project asset and is intended to be the starting point for the future app icon. Its final use as the official application icon may change as the launcher design evolves.

## 🚀 Development

1. Clone the repository.
2. Open it in Android Studio.
3. Let Gradle sync the project.
4. Build and run the `app` module on an Android device or emulator.
5. Future versions will progressively replace the foundation screen with the full CarsonDock desktop experience.
